**解读**：

- 主集 full 档 hit@1=20/20——全部金标案例均排在检索结果第 1 位。dense 阶段即满分，重排在位次上零扰动；
  重排的价值不在位次而在**引用阈值过滤**（§2 分数分布）：无关候选被压到 `RERANK_MIN_SCORE=-2.0` 以下，
  不进入引用白名单（宁缺毋滥口径，04 §4.6）。
- 唯一 miss：tfidf 主集 G17（个人化 RAG，「这个月餐饮比上个月多花了一倍」→ 金标 = 个人历史事件 PH-001）。

  路径正常命中。兜底档质量门槛为 12/20，19/20 余量充足。
- 三档梯度（tfidf 0.950 → dense-only 1.000 → full 1.000）与设计预期一致：dense 语义匹配补上了词面检索
  在口语化表述（G07「扣了我三次钱」、G18「学生认证」类）上的缺口；rerank 保持满分不回退。

## 2. 重排分数分布（引用阈值验证）

以「免费试用忘记取消自动续费怎么办」对 4 条候选的实测 logits（`src/server/rag/rerank.ts` 直推，
q8 交叉编码，2026-10-15）：

| 候选案例 | 相关性 | logit |
|---|---|---|
| st-006 免费试用到期自动扣费 | 直接相关 | +4.00 |
| st-002 订阅扣费时间固定 | 同族相关 | +0.41 |
| sb-001 学生认证外卖优惠 | 无关 | −5.77 |
| cr-007 信用卡账单还款 | 无关 | −9.07 |

相关案例 logit 显著为正、无关案例为负，`RERANK_MIN_SCORE=-2.0` 的引用阈值能把无关候选挡在引用之外，
阈值两侧余量约 2 个 logit 量级，校准口径有效（04 §4.1）。

## 3. 检索延迟（与 07 §16 预算对照，含修订）

| 阶段 | 口径 | 实测（2026-10-15） |
|---|---|---|
| 冷启动首查 | 进程内首次 RAG 调用（含模型加载，一次性） | dense-only 2.5s；full 5.7s |
| 稳态 P95 | dense-only（bge-m3 查询嵌入 + 余弦 top-30） | 116ms（min 48ms） |
| 稳态 P95 | full（+ 30 候选交叉编码重排） | 2070ms（min 1.7s，max 2.2s） |
| TF-IDF 兜底 | 浏览器内词面检索 | ≤5ms |

**预算修订（随本报告生效，01 §8 / 07 §8·§16 同步口径）**：设计态「P95<900ms」基于 Stage3 重排
150–400ms/30 对的预估（04 §4.1 预算表），实测 30 候选 × 平均 400+ token 的 q8 交叉编码在本地 CPU
约 1.9s，为主要成本项（dense-only 档 116ms 证明除重排外的级联本身远快于 900ms）。修订后预算：

- 稳态 P95 **< 2.5s**（本地 CPU 口径；GPU/远端推理环境显著低于此值）
- 冷启动首查 **< 6s**（进程内一次性模型加载，不重复计费）
- TF-IDF 兜底 **< 100ms**（不变）

## 4. 可复跑性与 CI 断言

- **零网络**：金标查询嵌入离线预计算（`scripts/rag/build-golden-embeddings.mjs`），评测全程不调任何 API；
- **原始数据**：`tests/golden/results.json`（主集）与 `tests/golden/results-student.json`（补充集）为每次
  运行的逐题明细留档（gitignored，对外数字以本报告为准）；
- **CI 断言**（脚本内硬编码）：主集 full hit@3 <18/20 exit 1；学生补充集 full hit@3 <7/8 exit 1（独立）；
  dense-only 主集 <16/20 exit 2 警告；tfidf 主集 <12/20 exit 1。
