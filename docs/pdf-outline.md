## 制作方式（D3 执行）

1. 先跑通全动线后截真实页面图（亮色为主，暗色 1-2 张体现切换）；
2. 每章文字以「结论先行 + 短段落 + 表格/图」呈现，评审 5 分钟阅读口径；
3. 架构图用 mermaid 渲染或 draw.io 导出 PNG；
4. 用 markdown → PDF 工具链（或 Word/LaTeX 排版）输出，页数校验 ≤30。
