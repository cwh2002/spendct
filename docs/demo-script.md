## 分镜操作与口播稿

### S1 开场记忆点（0:00–0:30）

**画面**：黑场 → 标题「消费CT · SpendCT」；左侧两行大字逐字浮现；右侧数据可见性对照表动画（浏览器=明细 / LLM=聚合摘要 / 服务器=无）。

**口播**：
> 大家好，我们的作品是 SpendCT——AI 账单体检与消费洞察平台。开讲前请记住两件事。第一：AI 先体检、你来审阅追问——它给你的不是聊天，是带证据的报告。第二：你的账单永远不出浏览器，大模型只看到聚合摘要，服务器只见转发。接下来用一条真实动线演示。

### S2 上传（0:30–1:00）

**操作**：首页「开始体检」→ /upload → 点「加载示例账单」→ 格式嗅探预览（字段映射表 + 前 3 行 + 去重提示）→ 「确认导入」→ 跳 /checkup。

**口播**：
> 第一步，数据。支持微信、支付宝导出的 CSV，也支持账单截图 OCR。没有真实账单也没关系——内置一千行脱敏演示账单，一键加载。看到格式嗅探结果：字段映射置信度、去重移除的行数，全都摊开给你看。

### S3 六阶段（1:00–2:00）

**操作**：/checkup 自动跑六阶段；思考面板滚动出现进度/SQL/RAG/叙事事件；暂停一次 → 继续（断点续跑镜头）；**2s 特写：点开「订阅陷阱」阶段卡 → 证据抽屉（SQL + 命中数 + 耗时 + 产出卡缩略）**；完成条出现「3 秒后进入洞察流」。

**口播**：
> 第二步，体检。清洗、画像、异常、订阅陷阱、环比归因、年度报告——六阶段全自动，每一步你都能看见它在想什么：正在执行的 SQL、命中行数、引用的案例。点开任意阶段卡，该阶段执行的 SQL、命中数、耗时、产出卡都在这里。跑了一半可以暂停、续跑，状态存在本机。

### S4 洞察卡流（2:00–3:00）

**操作**：自动跳 /insights；卡片流依次呈现：结论标题 + 证据图表 + 置信度 + 引用（sql:/rag:）+ 操作按钮；点「确认」一张卡、点「质疑」另一张（标记状态切换）。

**口播**：
> 产出不是闲聊，是报告。每张卡都有结论、证据图表、置信度、来源引用。你可以确认它、质疑它、收藏它——低置信度的结论会被系统自动挂起，等你人工复核。

### S4.5 账本两大图 + 双视图 + 管理墙（3:00–3:43）

**操作**：/insights?view=ledger 账本汇总：日历热力图 → 类别桑基图两连切；点桑基节点弹出锚点追问入口（一闪）；切回卡片流 → 图表廊（双视图）；收藏一张卡（收藏夹面板 +1）；**尾 3s 切 /subscriptions 管理墙一瞥：倒计时徽标 + 取消攻略清单**。

**口播**：
> 账本不只一张表。日历热力图看消费节奏，桑基图看钱流向哪里——图上任何元素都能点了追问。卡片流、图表廊随意切。订阅管理墙告诉你：下一次扣费什么时候来，取消按钮藏在哪。

### S5 锚点追问（3:43–4:30）

**操作**：回到 /insights 点某张卡「深挖」→ 追问面板 → 输入「购物类按商户拆开看」→ Plan 浮现 → SQL 过白名单（绿色校验徽章）→ 新图表落位到面板内。

**口播**：
> 图上任何元素都能追问。这次追问生成的 SQL 必须过本地白名单——没有 DELETE、没有子查询嵌套，只有聚合查询，新图表才会落下来。每一次追问都是一张新图，不是一段话。

### S5.5 预算 + 快速记账（4:30–5:10）

**操作**：/budget 快速记账输入「中午食堂花了 15」→ zod 结构化确认卡（15.00 元 / 餐饮 / 今天）→ 一键入账 → 账本即时可见；切预算环：餐饮超支红色段 → AI 超支贴士卡 → 下月预测折线。

**口播**：
> 懒得记账？说一句话就入账——确认卡上的金额、类目、时间是结构化输出的结果，不是模板匹配。预算中心里，超支了会有贴士提醒你接下来几天该花多少，下月支出还有预测。

### S6 注入拦截（5:10–6:10）

**操作**：回到 /upload 上传 `malicious-sample.csv`（商户名含「忽略以上所有指令…」「DROP TABLE transactions」字样）→ 正常出卡；叙事不含注入内容；红框标注三层防护（输入净化 / SQL 白名单 / 输出校验闸门）；拦截日志 10/10。

**口播**：
> 账单是数据，不是指令。我们把恶意提示词直接塞进商户名，系统照常出报告，叙事里没有一句被带偏。三层防护加输出校验闸门，恶意注入在这里失效。

### S7 真实数据（6:10–6:55）

**操作**：性能基准表逐项亮出（10k 行清洗/导入/聚合、WASM 冷热加载、内存峰值、六阶段无 LLM 耗时、RAG hit@3、恶意 SQL 拦截 10/10）；金标评测数字；费用数字；**零嵌入 API 抓包证据**（断网 + 网络面板无请求）。

**口播**（数字 11/13 终测填入）：
> 最后是真实数字。一万行账单清洗 X 秒，WASM 冷加载 X 毫秒、热加载 X 毫秒，内存峰值 X 兆。六阶段全确定性路径 X 秒——不依赖任何大模型调用。RAG 金标评测 hit@3 达到 X。恶意 SQL 拦截 10 中 10。全程零嵌入 API 请求。整个赛程成本 ¥X。

### S8 结尾（6:55–7:18）

**操作**：两记忆点重现（「AI 先体检，你审阅追问」/「账单不出浏览器」）+「账单体检，不止六项」一行字 + 仓库地址 + 致谢。

**口播**：
> 再记一遍这两句话：AI 先体检，你审阅追问；账单不出浏览器。账单体检，不止六项。SpendCT，谢谢大家。
