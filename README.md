# 消费CT · SpendCT —— AI 账单体检与消费洞察平台

> 2026 第九届传智杯「AI WEB 网页开发挑战赛」参赛作品（赛道 id=10037）

把微信、支付宝导出的账单 CSV 拖进浏览器，一条六阶段流水线自动完成清洗、画像、异常检测、订阅陷阱扫描、环比归因与年度报告，产出可确认、可质疑、可深挖的消费洞察卡。**账单解析与体检默认全在浏览器内完成，服务端只转发、零存储。**

## 为什么是 SpendCT

- **痛点**：自动续费悄悄扣款、深夜冲动消费、预算形同虚设——年轻人（尤其学生）缺的不是记账工具，而是「体检 + 处方」。
- **差异**：传统记账 App 只记录不诊断；SpendCT 用确定性 SQL（DuckDB-WASM）做体检主体，LLM 只负责叙事与建议，结论可溯源到聚合 SQL、法规条文与真实案例。
- **隐私**：账单解析、聚合、体检默认全在浏览器内完成；追问面板在线兜底时会把「汇总统计 + 最近 150 笔明细快照」发给大模型分析（08 修订案 A8），开启「深度分析」开关后发送全期统计 + 明细（08 修订案 A14），气泡都会按实际发送的账单数据段标注「已发送明细与统计」（深度分析为「已发送账单统计与明细」）；服务端只转发、零存储（见 [docs/02-data-privacy.md](docs/02-data-privacy.md) 的可见性对照表）。

## 功能总览

| 模块 | 说明 |
| --- | --- |
| 六阶段体检 | 清洗 → 消费画像 → 异常检测 → 订阅陷阱扫描 → 环比归因 → 年度报告，流式事件实时可见（21 类协议事件） |
| 洞察卡 | 每条结论带置信度、图表证据、SQL/RAG 引用，可确认 / 质疑 / 收藏 / 深挖；低置信度结论自动挂起 |
| 订阅雷达 | 洞察页第 5 视图「订阅管理」：确定性规则（同商户 ≥3 笔、间隔 25–40 天、金额 ±1% 容差）揪出连续扣费，每一笔可点开核对，附下次扣费倒计时与取消指引 |
| 消费日历 | 日历热力图（按日支出深浅着色）+ 时间轴流水（精确到秒、深夜标记），搜索与收支方向筛选、数据表视图，一眼看懂「钱花在哪些日子」（浏览器内白名单聚合，零 API） |
| 预算中心 | 12 类目预算环 + 超支贴士 + 下月预测 + 一句话快速记账 |
| 年度报告 | 健康指数（大白话总评 + 六维健康明细）+ 四项对标指标 + 滚动叙事 + 1080×1920 海报导出 |
| 知识课堂 | 60 条可核验案例（订阅陷阱 / 预付风险 / 消费维权 / 学生权益），附法条与官方来源 |
| 本地账户 | IndexedDB 账户体系（PBKDF2-SHA256 加盐哈希），注册 / 登录 / 个人中心 / 成就段位 |
| 数据主权 | 账单 CSV / JSON 一键导出、一键删除；数据可见性对照表公开在 /privacy |
| 智能助理 | 全局悬浮聊天抽屉（本地优先混合推理）：规则问答 + 案例检索零 API 兜底、在线兜底挂思考计划与工具徽章、语音输入（浏览器转写） |
| 商户统计 | 洞察页第 4 视图：按商户 / 支付单位聚合全账单支出——总额、笔数、占比、均笔金额，排名图 + 全量数据表 + 商户搜索，点击柱子直接追问（浏览器内白名单聚合，零 API） |
| 追问深度分析 | 追问面板「深度分析」开关（默认关、每问一次显式同意）：开启后直接交给大模型分析——发送全期白名单聚合统计 + 与问题直接相关的定向明细（按月份/年份/商户/类目/深夜检索，最多 200 笔）+ 最近 150 笔明细快照（精确到秒、深夜标记）（08 修订案 A14/A15），回答挂「深度分析 · 已发送账单统计与明细」脚注（按实际发送的统计/明细组合标注）；可接 DeepSeek API，也可配本地大模型端点（数据不出本机） |

## 技术架构

```
账单 CSV ──► 解析(编码探测UTF-8→GB18030→GBK/表头嗅探/去重) ──► DuckDB-WASM(浏览器内)
                                                  │
         ┌────────────────────────────────────────┤
         ▼                                        ▼
   SQL 白名单聚合(9 预计算表 + 13 视图)      LLM 接入层(mock/live 双模式)
         │                                        │  降级链 deepseek → qwen → 模板
         ▼                                        ▼
   六阶段管线引擎(状态机 + 断点续跑) ──► 洞察卡工厂 ──► reflect 发布闸门 ──► UI
         │
         └─► 21 类协议事件流(实时渲染到体检页)
```

- **AI 技术点**：Agent 六阶段工作流、反思自检闸门、模型降级链、RAG 案例库检索（60 条案例 + 本地关键词匹配）、MCP 工具链（校历 / 和风天气 / 大促日历 / 账单元数据回执四工具，Streamable HTTP + 本地回退双轨，连接失败自动降级）、结构化 LLM 短任务（快速记账 / 预算建议 / 预测叙事 / 贴士个性化）、截图 OCR 多模态（DeepSeek deepseek-flash 原生视觉主 + 智谱/SiliconFlow 降级网关，低置信字段截取原图局部二次复核）、LLM 生成 SQL 白名单拦截、全局智能助理本地优先混合推理（规则问答与案例检索先在浏览器本地作答，答不了才走在线兜底，非直连 API 聊天窗）、追问深度分析（显式同意开关 + 10 组全期白名单聚合 SQL 上下文 + DeepSeek/本地大模型端点双通道）。
- **工程**：Next.js 16（App Router）+ React 19 + TypeScript strict + Tailwind 4（CSS-first 令牌）+ Zustand + TanStack Query + ECharts（暗色主题经 CSS 变量桥接）。
- **安全**：SQL 窄文法白名单（7 原因码 + 行数复检）、金额全链路整数分、`check-secrets` 钩子杜绝密钥进库。

设计文档见 [docs/](docs/)（01 架构 / 02 数据隐私 / 03 Agent 流水线 / 04 RAG-MCP / 05 UIUX / 06 路线图 / 07 权威契约 / 08 功能扩展）。

## 快速开始

```bash
pnpm install          # postinstall 自动自托管 DuckDB-WASM 到 public/duckdb（断网演示可用）
cp .env.example .env.local
pnpm dev              # http://localhost:3000
```

- **零密钥演示**：不填任何 API key 即 mock 模式（演示账户 `demo` / `demo123`），「上传账单」页可用内置示例账单跑完整流程；
- **接入真实模型**：在 `.env.local` 填 `DEEPSEEK_API_KEY`（文本主脑 + 截图 OCR 主视觉模型 deepseek-flash，同一把密钥）；任一 key 就位即自动切 live 模式（`DEMO_MODE=mock` 可强制回零密钥演示）。截图 OCR 降级链：deepseek-flash → 智谱 glm-4.6v-flash（`GLM_API_KEY`）→ SiliconFlow GLM-4.1V-9B（`SILICONFLOW_API_KEY`）；`DEEPSEEK_VISION_MODEL` / `GLM_VISION_MODEL` / `SILICONFLOW_VISION_MODEL` 可覆盖模型名，未配任何视觉 key 时走 mock 剧本。
- **本地大模型（可选）**：同时配置 `LLM_BASE_URL` + `LLM_MODEL`（如 Ollama 的 `http://127.0.0.1:11434/v1` + `qwen3:8b`）后，追问在线兜底与深度分析改发该 OpenAI 兼容端点——账单数据不出本机；其余任务路由不变。
- **MCP 工具（可选）**：`.env.local` 填 `MCP_SERVER_URL`（如 `http://localhost:8317`）即接入真实工具链；未配置或连接失败时自动降级本地回退（校历/大促日历本地静态数据、天气诚实降级），不影响演示。mcp-server 独立启动见 [mcp-server/README.md](mcp-server/README.md)。

```bash
pnpm typecheck       # tsgo 全量类型检查
pnpm lint            # ESLint
pnpm test            # Vitest 单测（631 用例）
pnpm test:e2e        # Playwright 端到端（全路由冒烟 + 关键动线，55 用例）
pnpm build           # 生产构建（20 路由：13 静态页 + 6 API + not-found）
```

## 隐私承诺（写入产品）

1. 账单解析、聚合、体检默认全在浏览器内完成，明细不落盘、服务端零存储；
2. 追问面板在线兜底（本地答不了的问题）会把「汇总统计 + 最近 150 笔明细快照（精确到秒、深夜标记）」发给大模型分析（08 修订案 A8）；开启「深度分析」开关提问时发送「全期统计 + 与问题直接相关的定向明细（最多 200 笔）+ 明细快照」（08 修订案 A14/A15，每问一次显式同意），气泡按实际发送的账单数据段标注（两者都发送时为「已发送账单统计与明细」）；
3. 智能助理与追问面板共用输入闸门（指令覆盖 / 角色劫持 / 泄露诱导 / SQL 痕迹四类注入特征直接拦截）；语音输入由浏览器语音服务转写，音频与服务器、大模型零接触；
4. 服务端仅转发 LLM 请求，不存储任何请求日志；全部数据可一键导出、一键删除。

完整对照表见 [/privacy](https://spendct.vercel.app/privacy) 与 [docs/02-data-privacy.md](docs/02-data-privacy.md)。
